HOW TO RUN SHAGAR CHAMBER (XAMPP + Node.js)

The website, admin panel and API are one Next.js app in the "web" folder.

1. Open XAMPP Control Panel and start MySQL (and Apache for phpMyAdmin).
2. Go to http://localhost/phpmyadmin -> Import -> choose database.sql -> Go.
   (Safe to re-import on an existing database: it only adds what is missing.)
3. In the "web" folder, copy .env.example to .env.local. For XAMPP set:
      DB_HOST=127.0.0.1   DB_PORT=3306   DB_USER=root   DB_PASSWORD=   DB_SSL=false
4. Open a terminal in the "web" folder and run:
      npm install
      npm run create-admin
   Enter a username, email and password (12+ characters) for the admin.
   Run it again with the same email any time to reset that admin's password.
5. Start the site:
      npm run dev
6. Open in your browser:
      http://localhost:3000/              (website)
      http://localhost:3000/admin/login   (admin)

To put the site online, see web/README.md ("Hosting it online").
