HOW TO RUN SHAGGAR CHAMBER

The website, admin panel and API are one Next.js app in the "web" folder.
The database and uploaded files are in Supabase.

1. In the "web" folder, copy .env.example to .env.local and fill in
   SUPABASE_URL, SUPABASE_SECRET_KEY and SUPABASE_DB_URL (see web/README.md
   for where to find each one in the Supabase dashboard).
2. Open a terminal in the "web" folder and run:
      npm install
      npm run db:push
      npm run create-admin
   db:push creates the tables (safe to run again). create-admin asks for a
   username, email and password (12+ characters); run it again with the same
   email to reset that admin's password.
3. Start the site:
      npm run dev
4. Open in your browser:
      http://localhost:3000/              (website)
      http://localhost:3000/admin/login   (admin)

To put the site online, see web/README.md ("Hosting it online").
